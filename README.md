# TOC Study Studio

A static, GitHub Pages-friendly study website for JSSSTU course 24CS530 (Theory of Computation), focused on Units 1 and 2.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Deploy with GitHub Pages

1. Create a GitHub repository (for example, `toc-study-studio`).
2. Upload `index.html`, `styles.css`, `app.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.
6. Wait for the published URL shown in Settings → Pages.

## Current features

- Responsive dark Automata Lab visual theme and light/dark toggle
- Unit 1 and Unit 2 topic explorer
- Step-by-step DFA string tracer for strings ending in `ab` (Trace, Next step, Play/Pause, Reset)
- Visible transition table for the demo DFA
- Searchable/filterable Unit 1–2 question bank with expandable worked answers, DFA transition tables, conversion methods, pumping-lemma proof, and closure-property explanations
- Short interactive concept check
- Static HTML/CSS/JavaScript; no backend or API keys

## Content scope

The official syllabus determines the scope. Older uploaded notes and papers are supplementary and should only be used for material that matches Units 1 and 2. Unit 3 and later content is intentionally excluded. Question provenance is labelled inside the site: the dated 2022 Test-1 image is separated from questions gathered from older/undated notes. The question bank is not represented as a complete archive of all past papers. Continue verifying and expanding explanations and solutions from the supplied class materials before treating the site as complete revision notes.
